# แบบประเมินสมดุลองค์รวม — สิขรี เวลเนส แอนด์ สปา

เว็บแบบสอบถามประเมินสุขภาพตามหลัก **ธรรมนามัย ๓** (กายานามัย / จิตตานามัย / ชีวิตานามัย)
พร้อมออกรายงานวิเคราะห์ธาตุ ๔ และบันทึกเป็น PDF ขนาด A4 หน้าเดียว

## การใช้งาน

เปิด `index.html` ด้วยเบราว์เซอร์ได้ทันที ไม่ต้องติดตั้งหรือ build อะไร

1. กรอกข้อมูลผู้รับบริการ (ธาตุเจ้าเรือนคำนวณจากเดือนเกิดให้อัตโนมัติ)
2. ตอบคำถามทีละหมวด หมวดละหน้า — ไม่แสดงคะแนนระหว่างทำ
3. ดูรายงานผล แล้วกด **บันทึกเป็น PDF / พิมพ์** → เลือกปลายทาง “บันทึกเป็น PDF”, ขนาด A4, ปิด Headers and footers

ตัวอย่างผลลัพธ์: [`sample-report.pdf`](sample-report.pdf)

## แก้ไขคำถามและผลลัพธ์

กดปุ่ม ⚙ มุมขวาล่าง จะเปิดหน้าจัดการ แก้ได้โดยไม่ต้องแตะโค้ด

| แท็บ | แก้อะไรได้ |
|---|---|
| คำถาม | ข้อความ, เพิ่ม/ลบ/ย้ายลำดับ, ย้ายหมวด, ธาตุที่ผูก, ป้าย “คุณภาพการนอน” |
| เกณฑ์การให้คะแนน | ข้อความตัวเลือก 0–3 และจำนวนตัวเลือก |
| การแปรผล | ช่วงคะแนนกลุ่มเสี่ยง, ข้อสรุป, แนวทาง, เกณฑ์ตัดสินรายหมวดและธาตุ ๔ |
| ตารางกิจวัตร | ช่วงเวลาและกิจกรรมของแต่ละกลุ่มเสี่ยง |
| บริการที่แนะนำ | รายการบริการของแต่ละกลุ่มเสี่ยง |
| หัวรายงาน / ตัวชี้วัด | ชื่อรายงาน, หัวข้อ, disclaimer, ตัวชี้วัดความเสี่ยง |

การแก้ไขบันทึกลง **localStorage ของเบราว์เซอร์เครื่องนั้น** ถ้าต้องการย้ายไปเครื่องอื่น
ให้ใช้ปุ่ม **ส่งออก JSON** แล้วไป **นำเข้า JSON** ที่อีกเครื่อง

## บันทึกผลลง Google Sheet

เว็บนี้เป็น static site (ไม่มีเซิร์ฟเวอร์) จึงเก็บผลเองไม่ได้
ถ้าต้องการเก็บผลทุกครั้งที่มีคนทำแบบประเมิน ให้ต่อกับ Google Sheet ผ่าน Apps Script ตามนี้

**1. สร้างสคริปต์**
เปิด Google Sheet ที่ต้องการเก็บผล → เมนู **ส่วนขยาย › Apps Script**
ลบโค้ดเดิมทิ้ง แล้ววางเนื้อหาจาก [`apps-script/Code.gs`](apps-script/Code.gs) ลงไป
แก้ค่า `SECRET` เป็นข้อความลับของคุณเอง แล้วกดบันทึก

**2. Deploy**
กด **ทำให้ใช้งานได้ (Deploy) › การทำให้ใช้งานได้ใหม่** → ประเภท **เว็บแอป**
ตั้งค่า **ดำเนินการในฐานะ: ฉัน** และ **ผู้ที่มีสิทธิ์เข้าถึง: ทุกคน (Anyone)**
กด Deploy แล้วอนุญาตสิทธิ์ (จะมีหน้าเตือน "ยังไม่ได้ยืนยัน" ให้กด ขั้นสูง › ไปที่โปรเจ็กต์)
คัดลอก **URL ของเว็บแอป** ที่ลงท้ายด้วย `/exec`

**3. ตั้งค่าในเว็บ**
เปิดเว็บ → กดปุ่ม ⚙ → แท็บ **บันทึกผลลง Sheet**
เปิดใช้งาน, วาง URL, ใส่รหัสลับให้ตรงกับ `SECRET` แล้วกด **ทดสอบการเชื่อมต่อ**
ถ้าสำเร็จจะมีแถวทดสอบโผล่ในชีต (ลบทิ้งได้)

**สิ่งที่บันทึก** — แท็บชื่อ `ผลการประเมิน` จะถูกสร้างให้อัตโนมัติ หนึ่งแถวต่อหนึ่งการประเมิน
เก็บ เวลา, รหัสอ้างอิง, ชื่อ, ธาตุเจ้าเรือน, คะแนนรวม/เต็ม/สมดุล, กลุ่มเสี่ยง,
คะแนนรายหมวด, สภาวะธาตุ ๔, ระดับความเครียด, คุณภาพการนอน, ผลประเมินความเสี่ยง,
บริการที่แนะนำ และคำตอบรายข้อ
ถ้าเพิ่มคำถามใหม่ในภายหลัง คอลัมน์จะถูกต่อท้ายให้เอง ข้อมูลเดิมไม่เลื่อน

**ข้อควรทราบ**

- URL และรหัสลับฝังอยู่ในหน้าเว็บ ผู้ที่เปิดดูซอร์สโค้ดจะเห็นได้ — ใช้กันข้อมูลขยะได้ แต่ไม่ใช่การรักษาความลับระดับสูง
- ถ้าส่งไม่สำเร็จ (เน็ตหลุด) ผลจะถูกเก็บไว้ในเครื่องและส่งซ้ำอัตโนมัติเมื่อเปิดเว็บครั้งถัดไป ดูจำนวนที่ค้างได้ในแท็บเดียวกัน
- สคริปต์กันบันทึกซ้ำด้วยรหัสอ้างอิงอยู่แล้ว ส่งซ้ำได้โดยไม่เกิดแถวซ้ำ
- ทุกครั้งที่แก้ `Code.gs` ต้อง Deploy เวอร์ชันใหม่ ไม่งั้นของเดิมยังทำงานอยู่

## หมายเหตุ

- มีปุ่มสลับโหมดสว่าง/มืด แต่ PDF ที่พิมพ์ออกมาจะเป็นเอกสารสีอ่อนเสมอ
- คะแนนสมดุลองค์รวมคำนวณจาก `(คะแนนเต็ม − คะแนนรวม) ÷ คะแนนเต็ม × 100`
- รายงานนี้เป็นแนวทางดูแลสุขภาพเบื้องต้น ไม่ใช่การวินิจฉัยทางการแพทย์แผนปัจจุบัน
